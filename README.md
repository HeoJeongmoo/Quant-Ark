# 퀀트 오피스

한국투자증권(KIS) Open API로 미국 주식을 매매하는 서버 상주 봇과, 그 상태를 8명의 픽셀 에이전트로 보여 주는 대시보드입니다.
화면의 모든 숫자는 KIS에서 받은 실데이터이고, 서버가 없으면 아무것도 만들어 내지 않습니다.

## 빠른 시작 (Docker, 권장)

```bash
cp .env.example .env        # APP_KEY, APP_SECRET, CANO, KIS_ENV=demo 부터 채우기
docker compose up -d --build
```
- 대시보드: http://localhost:8787 (내 PC에서만 열림)
- 로그: `docker compose logs -f` / 끄기: `docker compose down`
- `restart: always` + 헬스체크(`/api/bot/health`) + 내부 감시견(봇 루프가 5분 멈추면 재시작)
- 체결 기록·설정·관심종목은 `./data`, KIS 토큰은 `./.kis-cache`에 남습니다.
- **PC가 절전에 들어가면 컨테이너도 멈춥니다.** 미국 정규장(한국 시각 겨울 23:30~06:00, 여름 22:30~05:00) 동안은 절전을 꺼 두세요. Windows는 Docker Desktop의 "Start Docker Desktop when you sign in"을 켜 두면 재부팅 후 자동으로 다시 뜹니다.

Docker 없이: `npm install` → `npm run build` → `npm run server` 후 http://localhost:8787
(화면 수정 중에는 `npm run dev`로 :5173에서 자동 새로고침)

## 환경 변수 (`.env`)

`.env`는 내 PC에만 두고 깃·압축 파일에 넣지 않습니다. 업데이트 압축 파일에도 `.env`와 `data/`는 들어 있지 않으니 풀어도 덮어쓰지 않습니다.

**채워야 하는 것** (지금 모두 채워져 있음)
| 변수 | 내용 |
|---|---|
| `KIS_ENV` | `real` 실전 / `demo` 모의투자 |
| `APP_KEY`, `APP_SECRET` | KIS Developers에서 발급 |
| `CANO`, `ACNT_PRDT_CD` | 계좌번호 앞 8자리 / 뒤 2자리 |
| `KIS_ENABLE_REAL_ORDERS` | `true`여야 실전 주문이 나감 |
| `ANTHROPIC_API_KEY`, `GEMINI_API_KEY` | 둘 중 하나만 있어도 됨 |
| `ALPHAVANTAGE_API_KEY` | 사무엘 뉴스 (없으면 야후·KIS만 사용) |
| 나머지 (`KIS_FEE_PCT`, `HARD_STOP_PCT`, `BOT_TICK_MS` 등) | `.env.example` 기본값 |

**비워 둬도 되는 것** (지금 비어 있음)
| 변수 | 비어 있으면 | 언제 채우나 |
|---|---|---|
| `LOCAL_API_TOKEN` | 설정 변경·주문·AI 호출 API에 비밀번호가 없음 | **채우는 것을 권장**. Tailscale 안의 내 기기만 접속할 수 있어 지금도 위험은 낮지만, 실제 주문 API라 한 겹 더 막아 두는 게 안전. 채우면 화면에서 처음 설정 변경·주문할 때 한 번 묻고 브라우저에 저장 |
| `BOT_MIN_TARGET_PCT` | 화면 설정값(기본 +3%) 사용 | 화면 대신 `.env`로 고정하고 싶을 때만 |
| `BOT_LOSS_CUT_PCT` | 화면 설정값 사용 | 위와 같음 |
| `TS_AUTHKEY` | 필요 없음 | Tailscale을 Docker 사이드카(아래 방법 B)로 쓸 때만 |

`LOCAL_API_TOKEN` 만들기 (PowerShell): `-join ((48..57)+(97..122) | Get-Random -Count 32 | % {[char]$_})` → 나온 값을 `.env`에 넣고 `docker compose up -d`

## 외부 네트워크에서 접속 (Tailscale)

내 기기끼리만 쓰는 사설망이라 인터넷에 포트를 열지 않습니다. `tailscale funnel`(인터넷 공개)은 쓰지 마세요.

**방법 A (지금 쓰는 방식): PC에 Tailscale 설치 + serve**
1. PC와 휴대폰에 같은 Tailscale 계정으로 로그인하고, 관리 페이지 DNS 탭에서 MagicDNS와 HTTPS 인증서를 켭니다.
2. PC에서 `tailscale serve --bg 8787` 한 번 실행 (재부팅해도 유지).
3. 휴대폰에서 `https://<PC 이름>.<tailnet 이름>.ts.net`으로 접속. `TS_AUTHKEY`는 필요 없습니다.

**방법 B: Docker 사이드카**
1. Settings → Keys에서 auth key를 만들어 `.env`의 `TS_AUTHKEY=`에 넣습니다.
2. `docker compose down` 후 `npm run docker:ts` (= `docker compose -f docker-compose.tailscale.yml up -d --build`).
3. 휴대폰에서 `https://quant-office.<tailnet 이름>.ts.net`. Machines 탭에서 Disable key expiry를 켜 두면 계속 붙어 있습니다.

## 봇이 하는 일 (server/bot)

뉴욕 시각(서머타임 자동)과 NYSE 휴장일·조기폐장일로 장 상태를 판단합니다 (`session.js`).

**정규장**
1. 시세: 보유 종목은 10초마다, 관심 종목은 약 30초마다. 보유 종목 1호가는 30초마다.
2. 5분봉: 봉이 닫힐 때마다 관심 종목 + 보유 종목 + QQQ.
3. 노아의 방주: QQQ가 전일 대비 또는 장중 고점 대비 `arkDropPct`(기본 1.5%) 이상 빠지면 신규 매수 중지.
4. S티어(A 변동성 돌파 / B 과매도 반등 / C 장 초반 갭) 신호 → 규칙 점검 → 켈리 수량 → (AI 키가 있으면) 노아 위험 점검·아브라함 결재 → 여호수아 매수.
5. 모세: 보유 종목 전부를 매 틱 판단 → 매도.
6. 다윗 탐색 ON이면 5분마다 KIS 순위 API로 후보를 찾아 AI 관심종목에 넣고, 다음 봉부터 S티어 스캔.

**매도 (모세, `moses.js`)**
- 강제 손절선(기본 -3%, `HARD_STOP_PCT`): 평단 대비 이 이하면 모드·AI와 무관하게 즉시 손절.
- AI 모드: 실제 5분봉의 이평·MACD·RSI, 1호가 잔량 비율, QQQ로 하락 압력을 세서 손절 / 수익 1% 이상이면 트레일링 익절.
- 수동 모드: 사용자가 정한 고정 손절·익절선.

**안심 체결 엔진 (`executor.js`)**
KIS 미국주식은 정규장 시장가 주문이 없어서(모의투자는 지정가만) "시장가"는 매수호가보다 충분히 낮은 지정가로 냅니다.
- 손절: 매수호가 -0.2% → 20초 미체결이면 취소 → -1% → 20초 → -3% → 이후 60초마다 -3% 재시도 (8회 실패 시 경보)
- 익절: 매수호가 → 45초 → -0.3% → 30초 → -1.5% → -3%
- 매수: 최우선 매도호가(상한 +0.3%) → 60초 안에 안 되면 잔량 취소, 추격 안 함
- 체결 확인: 주문체결내역(TTTS3035R / 모의 VTTS3035R), 취소: 정정취소(TTTT1004U / VTTT1004U)
- 체결 즉시 내부 잔고를 고치고 다음 틱에 KIS 잔고로 다시 맞춰 중복 매도를 막습니다.

**비용을 넘는 거래만 (진입 필터)**
- 왕복 비용 = 수수료 0.25% × 2 + 슬리피지·SEC Fee 여유 0.1% = **0.6%** (`KIS_FEE_PCT`, 화면에서 변경 가능)
- 예상 변동폭 = 5분봉 ATR% × √(보유 예정 봉 수, 기본 12봉 = 1시간). 이 값이 **목표 수익(기본 2%) 이상인 종목만** 진입합니다. 목표가 비용 이하로 설정되면 진입하지 않습니다.
- 매도도 같은 기준: 목표 수익에 닿아야 트레일링 시작, 트레일링 스톱은 평단 + 왕복 비용 아래로 내려가지 않음, AI 손절 기준 1%(압력 없을 땐 1.5%), 보유 예정 시간의 2배가 지나도 비용을 못 넘기면 시간 손절.
- 켈리 계산의 백테스트도 같은 목표·손절·보유시간·비용으로 하고, 기본 손익비도 비용 차감 후 값을 씁니다. 체결 기록의 손익도 수수료를 뺀 값입니다.
- 그래서 실거래 기록이 없을 때 켈리는 대부분 0 이하가 나옵니다(비용을 이길 근거가 아직 없음). **모의투자에서만** 이때 $500어치 "표본" 매수를 해서 실제 승률을 모읍니다 (`probeInDemo`). 실전에서는 켈리가 양수일 때만 삽니다.

**동시 신호 우선 매수** (`confluenceBuy`, 기본 켬)
- A·B·C 중 2개 이상이 같은 봉에서 켜지면 켈리·AI 결재 없이 매수. 총 평가금액의 10%(종목당 한도 안), 0주가 나오면 1주 가격이 한도 안일 때 1주.
- 계좌 보호 셧다운, 동시 보유 한도, 위험 상품, 거래대금, 변동폭(목표·상한), 방주, 예수금, `KIS_MAX_ORDER_USD`는 그대로 적용.
- 전략 성과 표의 "2개 이상 동시" 줄에서 이 거래들만 따로 볼 수 있습니다.

**위험 상품·위험 구간 제외** (`server/bot/risk.js`)
- 한투 상품기본정보(CTPF1702R)로 공식 분류를 확인해 제외: ETP 추적배수 ≠ 1(레버리지·인버스), PTP 종목(매도 대금 10% 원천징수), 상장폐지, 워런트·유닛·권리·우선주·채권형, 펀드(폐쇄형·수익형·BDC). 결과는 `data/product-info.json`에 7일 저장.
- 조회가 안 되면 종목명·티커(레버리지·인버스·VIX 상품 목록, 워런트형 티커)로 판별.
- 다윗 탐색 후보, 봇 매수, 직접 매수 모두에 적용. 지수 ETF(QQQ, SPY 등)는 탐색 후보에서만 뺌.
- 오늘 정규장 거래대금 $5M 미만(얇은 종목), 예상 변동폭 12% 초과(급등락 잡주)도 매수 안 함.
- `npm run kis:scan`에서 후보마다 분류·추적배수·PTP 여부를 보여 줍니다.

**계좌 보호 잠금**
- 거래일(뉴욕 날짜) 첫 계좌 조회의 총 평가금액이 기준. 오늘 손익이 **-5%**(`dailyLossPct`)에 닿으면 그날 셧다운: 신규 매수 전면 금지(직접 주문 포함), 봇 포지션 청산(`flattenOnShutdown`), 손절·매도는 계속. 다음 거래일 첫 조회 때 자동 해제. 상태는 `data/bot-guard.json`에 남아 재시작해도 유지됩니다.
- 동시 보유 최대 **5종목**(`maxPositions`, 진행 중인 매수 주문 포함). 넘으면 새 종목은 매수하지 않습니다(직접 주문 포함).
- 주의: 장중에 입금·출금·환전을 하면 평가금액이 바뀌어 오늘 손익 계산이 틀어질 수 있습니다.

**안전장치**
- 실전(`KIS_ENV=real`)은 `KIS_ENABLE_REAL_ORDERS=true`가 아니면 매수·매도 모두 주문안만 남깁니다.
- `KIS_MAX_ORDER_USD`는 매수에만 적용 (손절이 금액 한도에 막히지 않게).
- 잔고 조회 3회 연속 실패 → 비상 대기 (신규 매수 중지, 매도는 마지막 잔고로 계속).
- 마감 15분 전부터 신규 매수 안 함. 수동 제어 중에는 신규 매수 없이 신호만 기록.
- AI는 규칙 결정을 막거나 줄일 수만 있습니다. AI가 실패하면 규칙대로 진행합니다.

## 트랙 1: 장전 갭 스캐너 + 시가 범위 돌파 (D)

1. **장전 스캔** 뉴욕 08:30~09:25 (한국 겨울 22:30~23:25, 서머타임 21:30~22:25) 10분마다 상승률 순위(`updown-rate`, HHDFS76290000)를 봅니다.
   - 갭 +4~25%, 가격 $5~30, 프리마켓 거래량 50만 주 이상 또는 거래대금 $5M 이상
   - 시가총액(상장주식수 × 주가) $300M 이상, 위험 상품(레버리지·인버스·펀드 등) 제외
   - 점수 상위 5개를 `data/gap-candidates.json`에 저장하고 09:25에 확정합니다. 장전 스캔을 놓치면 개장 직후(09:30~09:45) 정규장 등락률로 한 번 만듭니다.
2. **진입(D)** 개장 후 첫 15분(5분봉 3개)의 고가·저가가 시가 범위입니다. 09:45~11:00 사이에 닫힌 5분봉이 아래 조건을 모두 채우면 매수 신호가 납니다.
   - 범위 고가 위에서 양봉으로 마감
   - 거래량이 범위 평균의 1.2배 이상
   - 고가에서 3% 넘게 달아나지 않음
   - 갭을 절반 넘게 반납하지 않음
   신호는 종목당 하루 한 번만 냅니다.
3. **손절** 범위 저가와 진입가 -2% 중 가까운 쪽을 손절가로 저장하고, 모세가 이탈 즉시 손절합니다. +3%부터는 기존 추적 익절이 동작합니다.
4. **수량** 아래 "매수 비중" 규칙(예상 승률 단계 또는 기존 방식)을 따릅니다. 갭 종목은 변동폭 상한을 30%로 따로 둡니다.
5. 같이 바뀐 기본값: 동시 보유 최대 3종목, 마감 5분 전 봇 포지션 청산, 마감 60분 전부터 신규 매수 금지.
   - 기존 설정 파일은 한 번만 이 값으로 옮겨지고, 그 뒤 화면에서 바꾼 값은 유지됩니다.
6. **1주 규칙(모든 트랙)** 켈리가 양수인데 계좌가 작아 0주가 나오면, 1주 가격이 종목당 한도 안일 때 1주를 삽니다.

거래 기록에는 `track`(gap / intraday)이 붙고, 전략 성과 표에 트랙별 행이 따로 나옵니다. `npm run kis:scan` 끝에 갭 후보 확인 섹션이 있습니다. 순위 API가 프리마켓 가격을 반영하는지는 장전에 이 명령으로 한 번 확인하세요.

## 상대 거래량 · 사무엘 뉴스 · 전략 자동 선택

- **상대 거래량(RVol)** = 오늘 지금까지 거래량 ÷ (최근 20거래일 평균 거래량 × 이 시각까지 보통 쌓이는 비율). 하루 거래량은 개장과 마감에 몰리는 U자 곡선으로 계산합니다.
  - 일봉 API(HHDFS76240000)로 종목당 하루 한 번만 조회합니다 (`data/avg-volume.json`).
  - 다윗 탐색은 RVol `rvolMin`(2배) 미만을 넣지 않고, RVol이 높은 순으로 정렬합니다.
  - 장중 매수는 `rvolMinEntry`(1.5배) 미만이면 막습니다. 갭 후보 D는 예외입니다.
  - 1주 가격이 종목당 한도를 넘는 종목도 탐색 단계에서 뺍니다.
- **갭 후보 점수**에 세 가지를 더합니다.
  - 프리마켓 RVol (프리마켓 거래량 ÷ 평소 하루 거래량)
  - 뉴스 재료
  - 상장주식수가 적은 정도 (KIS에는 유통주식수가 없어 상장주식수로 대신함)
- **사무엘 뉴스**: 세 곳에서 모아 같은 제목은 합칩니다. 종목별로 10분 캐시합니다.
  - **Alpha Vantage NEWS_SENTIMENT**: 종목별 기사와 감성 점수를 줍니다. `.env`에 `ALPHAVANTAGE_API_KEY`가 있을 때만 씁니다.
    - 무료는 하루 25회라 매수 직전 확인과 갭 후보 확정(09:25)에만 씁니다. 갭 확정 때도 8회는 매수용으로 남깁니다.
    - 결과는 종목당 60분 저장하고, 사용량은 `data/av-usage.json`에 셉니다.
    - 관련도 0.3 이상 기사의 감성 가중 평균이 -0.35 이하(Bearish, 2건 이상)면 막고, +0.25 이상이면 재료로 봅니다.
  - **야후 파이낸스 RSS**: 키가 필요 없습니다. Alpha Vantage를 못 쓰거나 결과가 0건일 때 씁니다. 비공식 피드라 403/429가 오면 30분 쉽니다.
  - **KIS 해외뉴스(HHPSTH60100C1)**: 한글 제목입니다. 종목 지정 조회가 0건이면 전체 뉴스에서 한글·영문 이름으로 찾습니다.
  - 공모·유상증자·희석·역분할·상장폐지·파산 같은 제목이 있으면 매수와 갭 후보를 막습니다.
  - AI 키가 있으면 제목을 사무엘에게 보여 주고 BLOCK/NEUTRAL/SUPPORT 의견을 받습니다. BLOCK만 효력이 있고, 밀어서 사게 하지는 않습니다.
- **전략 자동 선택 (Holly식)**
  - 매수 신호마다 "규칙대로 샀다면"을 5분봉으로 끝까지 따라가 가상 거래로 남깁니다 (`data/journal/shadow.jsonl`). 실제 주문 여부와 관계없이 기록하고, 켈리에는 섞지 않습니다.
  - 실거래가 `autoToggleMin`(30)건 이상 쌓이고 최근 기대값이 음수, PF가 1 미만인 전략은 자동으로 끕니다.
  - 꺼진 뒤 가상 거래 15건 이상에서 기대값이 양수, PF 1.1 이상이 되면 다시 켭니다.
  - 가상 탭의 전략 승격 표에서 전략마다 자동/켬/끔을 고정할 수 있습니다.

`npm run kis:scan` 끝에 일봉·KIS 뉴스 확인 섹션이 있고, `npm run news:check -- TSLA`로 Alpha Vantage·야후·KIS 뉴스와 사무엘 판단을 한 번에 확인할 수 있습니다.

## 뉴스 속보 · 손익 캘린더 (화면)

- **뉴스 속보** (사내 메신저 아래): KIS 전체 뉴스는 3분마다, 수동·갭·보유 종목 뉴스는 야후·KIS로 함께 모읍니다. Alpha Vantage 한도는 쓰지 않습니다.
  - 시각은 한국 시각이고, 30분 이내 기사에는 "속보" 표시가 붙습니다.
  - 전체 / 내 종목 / 재료·악재 탭으로 나눠 보고, 종목 칩을 누르면 그 종목 차트로 갑니다.
- **손익 캘린더**: 봇이 계좌를 조회할 때마다 그날(뉴욕 거래일) 평가금액을 `data/equity-daily.json`에 남깁니다.
  - 날짜별 손익 = 그날 마지막 평가금액 − 전 거래일 마지막 평가금액입니다.
  - "실현 손익" 보기는 청산된 거래(수수료 차감) 합계입니다.
  - 입출금·환전한 날은 평가금액 손익에 그 금액이 섞입니다.

## 가상 거래 체결 가정 (보수적)

가상 거래는 실제 주문 방식에 맞춰 불리하게 체결된다고 가정합니다.
- **진입**: 신호 다음 봉 시가 + 0.1% (`shadowEntrySlipPct`). 시가가 신호가보다 0.3% 넘게 높으면 실제로도 못 샀다고 보고 "미체결"로 버립니다.
- **손절**: 손절가 − 0.2% (`shadowStopSlipPct`). 봉이 손절가 아래에서 시작하면 그 시가 − 0.2%로 체결된 것으로 봅니다. 한 봉에서 손절과 목표가 모두 닿으면 손절로 처리합니다.
- **목표**: 고가가 목표가를 0.05% 넘어야 체결로 봅니다.
- **시간 청산·마감 청산**: 종가 − 0.1%
- 이 방식 이전(완벽 체결 가정)에 쌓인 기록은 거래당 0.3%p(`SHADOW_LEGACY_HAIRCUT_PCT`)를 깎아서 승격·승률 계산에 씁니다.
- 가상 탭의 "가상 매매 기록"에서 진행 중인 가상 포지션과 최근 청산 결과를 볼 수 있습니다. 같은 종목·전략·청산 방식은 뉴욕 기준 하루 1건만 기록합니다.

## 전략 승격 (D 외 전부)

D(트랙 1)를 뺀 모든 전략은 가상 거래로만 성적을 재다가, 승격 조건을 모두 넘어야 실제로 매수합니다. 기존 A·B·C도 같은 기준을 거칩니다 (예전 가상 거래는 같은 목표·손절의 청산 규칙으로 이어서 셉니다).

| 후보 | 진입 조건 (마감된 5분봉, 오늘 정규장) |
|---|---|
| E VWAP 회복 | 직전 봉은 VWAP 아래, 이번 봉이 VWAP 위로 양봉 마감, 거래량 최근 10봉 평균의 1.3배 이상 |
| F 장중 고점 돌파 | 직전 6봉 횡보폭 1.5% 이하, 당일 고점 위로 양봉 마감, 거래량 1.5배 이상 |
| G 레드 투 그린 | 전일 종가 아래에서 시작해 처음으로 전일 종가 위 양봉 마감 |
| H NR7 돌파 | 직전 봉이 최근 7봉 중 가장 좁고, 이번 봉이 그 고가 위 양봉 마감 |
| I 불 플래그 | 4봉 안 +3% 급등 → 거래량 줄며 절반 이내 눌림(2~5봉) → 직전 봉 고가 위 양봉 |

- 신호마다 청산 규칙 3종으로 따로 기록합니다: P1 짧게(+2%/−1%, 2시간), P2 기본(+3%/−1.5%, 3시간), P3 길게(+5%/−2%, 4시간).
- J~N 진입 조건은 아래 "전략 명부" 절 참고.
- **승격 조건** (최근 80건 기준, 모두 만족)
  - 가상 거래 40건 이상 (`promoteMin`)
  - 비용 뺀 기대값 +0.3% 이상 (`promoteExp`)
  - PF 1.3 이상 (`promotePF`)
  - 서로 다른 거래일 15일 이상 (`promoteDays`)
  - 앞쪽 절반과 뒤쪽 절반 모두 기대값 플러스
  - 후보가 8개를 넘으면 2개마다 기대값 +0.1%p · 건수 +10 (지금 후보 10개 → +0.4% · 50건)
  - 전체로는 미달이어도 매수 순간 장세(강세/보합/약세) 하나에서 통과하면 그 장세일 때만 매수 (장세 한정 승격)
- 통과한 청산 규칙 중 기대값이 가장 높은 것으로 매매합니다. 목표에 닿으면 바로 익절하고, 손절가와 보유 시간도 그 규칙을 따릅니다.
- 매수 비중 방식은 두 가지예요(운용 지침 "매수 수량"에서 전환). **예상 승률 단계**(`sizeMode: tier`)는 소액 계좌용으로 임시로 쓰고, **기존 방식**(`sizeMode: fixed`)은 종목당 10% 고정·최대 15%로 사다가 실거래와 계좌 조건이 차면 하프 켈리로 넘어가요. `sizeTierUntilEquity`를 정해 두면 계좌가 그 금액 이상일 때 자동으로 기존 방식으로 바뀝니다.
- 예상 승률 단계 방식은 이렇게 정합니다. 예상 승률은 그 전략·청산 규칙의 가상 거래와 실거래(2배 가중)를 합쳐 계산하고, 본전 승률 = (손절 + 왕복 비용) ÷ (익절 + 손절)과 비교합니다.
  | 단계 | 조건 | 비중 (총 평가금액 기준) |
  |---|---|---|
  | 검증 전 | 표본 20건 미만 | 25% |
  | 본전 근처 | 본전 승률 +3%p 미만 | 15% |
  | 보통 | 본전 승률 +3%p 이상 | 33% (보유 3종목 기준 1/3) |
  | 높음 | 본전 승률 +10%p 이상 | 45% |
  종목당 최대 비중(`maxW`, 기본 50%) 안에서 사고, 0주가 나오면 1주 가격이 한도 안일 때 1주를 삽니다. 그 전략 실거래가 `minObservedForKelly`(20)건 이상이고 총 평가금액이 `kellyMinEquity`($2,000) 이상이면 하프 켈리로 바꾸고, 켈리가 0 이하면 사지 않습니다.
- 매수 직전 AI 점검은 노아 한 번입니다(막기만 함). 예전의 "A·B·C 중 2개 이상이면 무조건 매수"와 모의투자 표본 진입은 없앴습니다.
- 성적이 기준 아래로 떨어지면 자동으로 관찰 상태로 내려갑니다. 실거래 30건 기준의 자동 끄기도 똑같이 적용됩니다.
- 가상 탭의 "전략 승격" 표에서 청산별 진행 상황(건수, 거래일, 기대값, PF)을 볼 수 있고, 전략마다 자동 / 승격 / 관찰을 고정할 수 있습니다. 모바일에서는 목록을 누르면 팝업으로 보입니다.

## 가상 전용 종목 (고정 + 자동)

- 가상 거래(A~I)는 **가상 전용 종목**과 **갭 후보**에서만 기록. 관심 종목·AI 추천은 가상 기록 안 함
- 고정 8개 (기본 AAPL·MSFT·NVDA·AMZN·META·TSLA·SPY·QQQ): 기준선
- 자동 5개: 뉴욕 09:20 이후 KIS 거래량 급증·체결강도·거래대금 상위에서 뽑고 그날은 고정 (`data/shadow-universe.json`)
- 가상 전용 종목은 실매수 안 함. 5분봉만 받고 현재가는 10분마다
- 편집: 성과 탭 → 가상 매매 기록 → 편집
- 같은 종목·전략·청산 방식은 뉴욕 기준 하루 1건만 기록
- 초기화: `SHADOW_EPOCH`가 오르면 시작 때 `data/journal/shadow.jsonl`을 `shadow.epochN-날짜.bak.jsonl`로 옮기고 새로 시작 (지금 2)

- 탭: 매매 / 성과 / 가상 / 설정. 성과 탭 = 실제 돈만, 가상 탭 = 가상 성적 전부
- 요약 줄: 진행 중 · 오늘 청산 · 오늘 1등 · 승격 근접 (기대값 플러스 중 건수·거래일 진행이 가장 큰 것)
- 가상 캘린더 (`/api/bot/shadowcal?month=`): 일 = 그날 1등 (재미용), 주 = 주별 1~3등과 플러스 전략 수 (흐름 파악), 월 = 전략·청산별 누적 (승격 판단)
- 승격 조건에 **서로 다른 거래일 15일 이상** 추가 (`promoteDays`, 설정 탭에서 변경)
- 가상 기록은 매일 지워지지 않고 계속 쌓임. 매일 새로 시작하는 건 자동 종목·하루 1회 제한·진행 중 가상 거래(장 마감 청산)

## 장세 기록 (Regime) — 전부 KIS 데이터

- QQQ 5분봉 (5분마다): 등락률 → 강세 +0.5%↑ / 약세 −0.5%↓ / 보합, 시가 갭, 장중 변동폭 ÷ 20일 평균 (높음 1.3배↑ / 낮음 0.7배↓), 추세 효율 (종가−시가)/(고가−저가) → 추세 |0.6|↑ / 횡보 |0.3|↓, 5분 수익률 기반 장중 변동성
- 시장 폭 대체 (10분마다): 섹터 ETF 11개 중 상승 수 (넓음 8↑ / 좁음 4↓), RSP − SPY (동일가중 − 시총가중)
- VIX 대체: VIXY 등락률
- 소형주: IWM 등락률 · QQQ − IWM (플러스면 대형주 장, 마이너스면 소형주 장) · SPY 등락률
- **가상 매수 순간**의 장세를 거래마다 같이 저장 (`regime`) → 나중에 필터로 쓸 수 있는 정보 (그 시점까지 알 수 있던 값만)
- **하루 값**은 `data/regime-days.json`에 날짜별 저장 → 가상 캘린더에 표시 (일: 모서리 글자·누르면 상세, 주: 장세 일수, 월: 강세/보합/약세별 평균)
- 추가 호출: 현재가 14개 / 10분 + QQQ 일봉 하루 1번
